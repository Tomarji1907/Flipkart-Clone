## Overview

This project is a **frontend implementation inspired by the Flipkart shopping experience**.

It focuses on creating a realistic e-commerce interface where users can browse products, explore categories, search for items, view offers, manage their cart and interact with the website across desktop and mobile devices.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔎 Product Search | Search products dynamically by name or category |
| 🗂️ Categories | Browse products through multiple categories |
| 🛒 Shopping Cart | Add products and maintain cart state |
| 🎞️ Promotional Slider | Rotating promotional banners and offers |
| 📍 Location | Delivery location / pincode interaction |
| 💰 Product Pricing | Price, MRP and discount information |
| ⭐ Ratings | Product ratings and review information |
| 🔃 Sorting | Sort products according to different options |
| 📱 Responsive UI | Optimized for desktop, tablet and mobile |
| 🔔 Notifications | Interactive toast feedback |
| 💾 LocalStorage | Preserve client-side shopping data |
