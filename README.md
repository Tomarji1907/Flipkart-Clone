## 🛍️ About The Project

**Flipkart Clone** is a responsive e-commerce website inspired by the Flipkart shopping experience.

The website is designed to feel like a real online shopping platform, with product browsing, categories, search, promotional banners, offers, cart interactions and a dedicated mobile experience.

---

# ✨ Features

### 🏠 Home

- 🛍️ E-commerce style homepage
- 🎞️ Promotional banners
- 🔄 Automatic banner slider
- 🔥 Best deals section
- 🗂️ Quick categories
- ✨ Featured products
- 📱 Responsive layout
